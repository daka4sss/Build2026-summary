## チャプター3: インフラ — Performance＝Tokens、Maia/Cobalt、データ基盤（4:00頃〜）

Satyaの基調講演で示された「Performance equals tokens（性能＝トークン）」を軸に、エッジとクラウド両面の刷新を解説。

### コストと効率
- 「同じ性能をいかに効率よく（少ないトークン・適切なコストで）実行できるか」が重要
- 近年GPU等の利用料が上昇しており、コストと性能のバランスを取ることが必須メッセージ

### エッジ側のイノベーション
- **Arm-metered intelligence**（自動字幕表記、固有名詞不確実）: PCのエッジ側でGPUとNPUを最適に組み合わせAI処理を最適化
- 単なる高速化ではなく **ローカルfoundry（Foundry Local）** を含め、Windows側とエッジ側の両方でモデルを動かす技術を提供

### サーバー側のイノベーション（自社開発チップ）
- 3年前に発表した **Maia / Cobalt** の後継として **Maia 200 / Cobalt 200** を発表
  - **Maia 200**: AI処理最適化チップセット
  - **Cobalt 200**: Armベースアーキテクチャ、エージェントアプリ等を効率的に実行
- （5:37頃 Maia/Cobalt 言及）

### データ層
- **Azure Horizon DB**（自動字幕 "Azure Horazon David"、固有名詞不確実）: PostgreSQL互換のオープンソースDBをマネージドで提供、大規模OLTPに対応、**Public Preview** 発表

- **Fabric Data Warehouse の GPU アクセラレーション**: NVIDIAのアクセラレーテッドコンピューティングと組み合わせ、クエリ性能を**最大7倍**に。アプリ無変更で高速データウェアハウスを実現（7:00頃）
- 背景: エージェントがますますDBにアクセスするため、それに耐えるデータアーキテクチャが重要

### Microsoft IQ ファミリー（コンテキスト基盤）
- これまで Work IQ / Public IQ / Foundry IQ を提示してきたが、新たに **Web IQ** を発表（8:00頃）
  - エージェント処理に最適化されたエンジンで Web grounding をサポート。従来より高速・低コスト
- **Work IQ API が GA** に。Copilotだけでなく自社アプリでも同様のデータ活用を可能にする点がポイント

### 1. AIデータセンター（40:08頃）
- モデル本体だけでなく**それを支えるインフラが重要**。直近1年半でMicrosoftは「Azure黎明期の最初の10年分に匹敵する」データセンター容量を拡張
- Copilot等の利用時にセッションが起動しコンテナが次々立ち上がるため、容量・GPUを備えたインフラが極めて重要
- **Fairwater**: AI専用データセンターの建設を開始（41:00頃、Satya基調講演でも言及）
- 拡張の原則: 地域の電気料金を上げない、水を循環させ実消費をゼロに近づける等、持続可能性に配慮
- データセンターでは自社開発チップ **Maia / Cobalt** が稼働。データセンター・チップ・OS・開発者ツールのフルスタックで価値提供

### 2. GitHub Copilot モダナイゼーション（41:30頃）
- GA ではなく機能拡張だが、モダナイゼーションの進め方そのものを変えると評価

- GitHub Copilot の追加で、開発・ITチームが同じ基盤上でモダナイゼーションを推進可能に
- **デモ画面**（43:03頃）: VS Code でソースコードフォルダを開き、GitHub modernization 拡張を起動。Javaアプリでアセスメント実行（規模により約20分）。クラウド移行方法・変更点を即座に提示
- **最大の変更点**（43:43頃）: 右側の Rulebook / Command Center と、対応シナリオの拡大。特に赤枠の**メインフレーム**対応が追加。メインフレームで動くアプリを今も持つ顧客の声に対応
- 日本のパートナー（**日立、NTT DATA**）とも GitHub Copilot モダナイゼーションを経験済み

### 3. Layfin（自動字幕表記、製品名不確実、44:50頃）
- AI時代にアプリ／モックアップ作成は容易になったが、本番レベルへ持っていくのが難しい。バックエンド（認証・運用・ガバナンス等）の構築が困難
- **Layfin** は AI と Microsoft が提供。**Fabric の力**を使い、バックエンドを含む本番レベルのアプリ利用を可能にするプロジェクト。**Public Preview** で発表
