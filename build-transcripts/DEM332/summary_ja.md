# Microsoft Build 2026 DEM332「From zero to teammate in 25 minutes: Build a Teams agent live」詳細まとめ

**登壇者**: Umang（Microsoft Teams プラットフォーム シニアプロダクトマネージャー）、Aamir（Microsoft Teams SDK シニアソフトウェアエンジニア）

## 全体像

本セッションは25分以内にゼロから Teams 上で動作するエージェントを構築するライブデモ形式の発表（DEM系）。Umang が設計思想と新機能の概要を解説し、Aamir が実際のコーディングとデモを担当した。

デモのコアテーマは「既存の Web アプリケーションをできるだけ少ない手間で Microsoft Teams のエージェントとして動かし、最終的に M365 エコシステム全体に存在する『チームメイト』に昇格させる」というものである。そのために新しい **Teams CLI** と **Copilot の Teams Dev Agent スキル**、そして **Agent 365（エージェント向け M365 アイデンティティ）** の3つが連携して動作する姿を示した。

ライブデモでは一部操作のミス（"whoops, sorry, this is a live demo"）があったものの大きな障害なく完了し、会場の笑いを誘う場面もあった。Agent 365 のパートはライブではなく録画ビデオで披露された（"This one is actually a demo, sorry a video just in the interest of time."）。

## チャプター2: Teams SDK の進化と3つの設計思想（1:10頃）

### Teams SDK（昨年→今年の変化）

| 年 | 発表内容 |
|---|---|
| Build 2025（昨年） | **Teams AI Library**（TypeScript・C#）、1対1チャットのエージェント機能（ストリーミング、フィードバックループ、フォローアップ、引用、スタータープロンプト） |
| Build 2026（今年） | **Teams SDK**（全ライブラリ・ツールを一本化した統合開発体験）、グループUX機能の大幅追加、他の Microsoft SDK とのインテグレーション強化 |

昨年から Cursor、Linear、Perplexity、Datadog、Atlassian などのパートナーが Teams SDK 上でビルドしており、320百万人のデイリーアクティブユーザーへのリーチを活用している。

### 3つの設計ピラー

Teams 上でエージェントを成功させるためのゴールを3本柱に整理：

**ピラー1: Bring Any Agent（任意スタックのエージェントを持ち込める）**
- Foundry、Vercel（トランスクリプトでは "Versail"）、CrewAI（"crew AI"）、Replit など、エージェントがどこに存在するかを問わない
- 「私たちはエージェントの住処に関してオピニオンを持たない」とUmangが明言（"We are unordinated about where your agent lives"）

**ピラー2: Frictionless Scaffolding（摩擦のないスキャフォールディング）**
- 開発者がエージェントを Teams に載せる際の認知的オーバーヘッドを最小化
- Teams CLI と Copilot の Teams Dev Agent スキルが担う

**ピラー3: Make it a Teammate（チームメイト化）**
- エージェントに独自アイデンティティを付与し、M365 エコシステム全体でのプレゼンスを確立
- 「エージェントのUXループを閉じる」という表現を使用

## チャプター4: Teams CLI によるエージェント登録（5:00頃）

### `teams app create` コマンドの実行

```
teams app create
```

Aamir がターミナルで上記コマンドを実行。対話形式で以下を設定：

1. **アプリ名**: `project management agent`
2. **メッセージングエンドポイントURL**: スキップ（後で設定）
3. **クレデンシャルの保存先**: `.env ファイル`
4. **カスタマイズ設定**: スキップ
5. **create** で確定

このコマンド1つが内部で以下をすべて自動実行：
- Entra アプリケーションの作成
- ボットの作成
- シークレットの生成
- 各要素の紐付け（グルー）
- **インストールリンクの発行**（Teams にインストール可能な URL）

従来は「アプリ登録 → 認証情報取得 → エンドポイント設定 → マニフェストアップロード → 環境設定 → ボット起動」という複数ステップをまたぐ長い旅が必要だったが、CLI により大幅短縮された。

### Teams CLI の設計思想：人間とエージェント両方向けに設計

CLI は「ヒューマンファースト」かつ「エージェントファースト」の2軸で設計されている。

**人間向け（インタラクティブモード）**

```
teams app
```

矢印キーでサブコマンドを選択できる対話式メニュー。実際にAamirが「project management helper app」を選択し、以下の操作が可能なことを示した：
- アプリ詳細の取得
- アプリの更新
- パッケージのダウンロード（同僚との共有用）
- シークレット管理
- パーミッション管理

デモ中に説明フィールドを「Use this to manage your project」に変更するライブ操作も披露（タイポしたが "Can't spell, but that's OK." と笑いを誘った）。

**エージェント向け: Progressive Disclosure（段階的開示）**

`teams -h` でトップレベルコマンドのみ表示：

```
teams app       # アプリ管理
teams project   # プロジェクト作成・設定
```

エージェントが特定のゴール（例：フィールドの更新）を持つ場合：
1. まず `teams app -h` でサブコマンドを確認
2. 次に `teams app update -h` で更新に必要なフラグのみ取得

エージェントのコンテキストウィンドウに**必要な情報だけ**を段階的に積み込む設計。不要なコンテキスト汚染を防ぎ、LLMの効率的な動作を実現する。

**エージェント向け: JSON モード**

```
teams app list
teams app get <ID>
teams app get <ID> --json
```

通常出力は人間向けの見やすいフォーマット（インストールリンク等含む整形表示）だが、`--json` フラグを付けると構造化された JSON 出力に切り替わる。エージェントはこれをスクリプト内でパースせず直接消費でき、複雑なパイプラインでも動作する。

## チャプター5: Copilot（Teams Dev Agent スキル）による自動インテグレーション（6:50頃）

### Copilot を "YOLO モード" で使用

Aamir が「Teams SDK パッケージをダウンロードして、ドキュメントを読んで、コードに組み込む…という従来の作業の代わりに Copilot を使う」と宣言。

VS Code（または類似環境）の Copilot を **YOLO モード**（承認なしで自動実行するモード）で起動し、以下のプロンプトを入力：

```
integrate this application into Microsoft Teams.
Once you're done, give me the installation link.
```

Copilot は自動的に **Teams Dev Agent スキル**をピックアップ。このスキルは2つの能力を持つ：
1. **Teams CLI との連携**（実際にCLIコマンドを実行して各種設定を行う）
2. **Teams ドキュメントの参照**（Teams SDK の最新ドキュメントを読んで実装判断をする）

Copilot が自律的に動作している間、Aamir は CLI の機能を会場に解説（前チャプター）。

Copilot の作業完了後、ログを確認：
- エンドポイントのセットアップ完了
- アプリの編集完了
- **インストールリンクの発行**

## チャプター7: グループUX 新機能のスニークピーク（14:00頃）

Umang が登壇し、グループチャット向けの新機能群を紹介（翌日11:50のセッションで詳細を解説予定）。

| 機能 | 詳細 |
|------|------|
| **Emoji Reactions（絵文字リアクション）** | エージェントが絵文字でメッセージに反応できる |
| **Targeted Messages（ターゲットメッセージ）** | エージェントがグループチャット内でユーザーにプライベートメッセージを送信可能 |
| **Slash Commands（スラッシュコマンド）** | グループチャット内でユーザーがエージェントにスラッシュコマンドで命令できる。ユーザーがエージェントにプライベートメッセージも可能（「恥ずかしい質問もこっそりできる」と説明）|
| **Quoted Replies（引用返信）** | エージェントが過去のメッセージを引用して返信可能。長時間タスクやメッセージの多いグループチャットで有効 |
| **Suggested Actions（サジェストアクション）** | エージェントがユーザーへの次のアクションを提案 |
| **Markdown Support（マークダウンサポート）** | グループチャット内でもマークダウン形式の返信が可能 |
| **Source Citations（ソース引用）** | 昨年Build で発表済みの機能を引き継ぎ・拡充 |

これらは Teams SDK の新しいグループUX機能として提供される。

## チャプター8: Agent 365 ─ エージェントをチームメイトへ変換（ビデオデモ）（15:10頃）

Umang が「ここからが本当の楽しいパート」と前置きし、**Agent 365** の概念とデモを紹介。このパートは「時間の都合上ビデオ」と断って録画を再生。

### Agent 365 とは

> 「M365 が人間向けであるように、Agent 365 はエージェント向けのものだ」— Umang

エージェントに **M365 アイデンティティ**（独自エイリアス・独自メールアドレス）を付与し、人間のユーザーと同様に M365 エコシステム全体に存在させる仕組み。

これにより「真のチームメイト」として：
- Teams でメッセージを送受信
- グループチャットに人間のメンバーと同様に追加
- メール（Outlook）を自身のアドレスから送信
- Word のコメントでメンション
- 会議に参加
- PowerPoint・Excel などの各アプリ内で動作

**IT 管理者側のメリット**：
- エージェントへの可視性（visibility）・観測可能性（observability）が向上
- パーミッションとコントロールが強化
- エージェントが与えるインパクトの把握が容易に

### ビデオデモの内容

1. **ブループリントからのエージェント生成**: 先ほど Aamir が構築した「project management agent」を**ブループリント**として使用。「Mobile Redesign」プロジェクト専用のプロジェクトマネージャーエージェントを作成
2. **独自アイデンティティの付与**: 作成時にエイリアスとメールアドレスが割り当てられる
3. **1対1チャット**: エージェントと直接チャット。「プロジェクトの現状は?」と聞くと、このエージェントは Mobile Redesign プロジェクトのみを担当しているため、特定のプロジェクト名を言わなくても自動的にそのプロジェクトの状況を回答
4. **グループチャットへの追加**: 人間を追加するのと全く同じ操作でグループチャットに追加。追加後にグループで話しかけると Mobile Redesign プロジェクトのサポートを開始
5. **メール送信デモ（ハイライト）**: グループチャット内でエージェントに「プロジェクトのサマリーをメールで送って」と依頼 → Outlook を開くと、**Mobile Redesign Project Manager エージェント自身のアドレスからメールが届いている**。連絡先カードにホバーすると「AI エージェント」であることが明示される

Umang が興奮気味に再確認：「Teams を離れることなく、エージェント（チームメイト）に自分のメールアドレスからメールを送らせることができた。これが真の意味で仕事が Teams で完結するということだ」

## まとめ

### セッションの結論

本セッションでは「ゼロから25分でチームメイトへ」というタイトル通り、既存 Web アプリを Teams エージェントに変換し、さらに M365 アイデンティティを持つチームメイトに昇格させるまでの一連のフローをライブデモで示した。

### 発表された新機能・新製品

| 機能名 | ステータス | 説明 |
|--------|-----------|------|
| **Teams SDK** | Public Preview（推測） | Teams AI Library を含む全ライブラリ・ツールを統合した新しい開発体験 |
| **Teams CLI** | Public Preview（推測） | `teams app create` 等のコマンドによるエージェント登録・管理ツール。人間向けインタラクティブモードとエージェント向けの Progressive Disclosure・JSON モードを備える |
| **Teams Dev Agent スキル（Copilot スキル）** | Public Preview（推測） | Copilot に Teams CLI 操作能力と Teams ドキュメント参照能力を付与するスキル |
| **Agent 365** | Private Preview / 近日発表（推測） | エージェントに M365 アイデンティティ（独自エイリアス・メールアドレス）を付与し、チームメイトとして M365 全体に存在させる機能 |
| **グループチャット向けUX機能（Teams SDK）** | Public Preview（推測） | Emoji Reactions、Targeted Messages、Slash Commands、Quoted Replies、Suggested Actions、Markdown Support、Source Citations |

※ GA/Public Preview/Private Preview の正式区分はトランスクリプト内で明示されていないため上記は推測。詳細は公式ドキュメントを参照のこと。
